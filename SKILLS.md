# Skills do projeto

Este catálogo é compartilhado pelo Codex e pelo Claude. As 39 skills foram
instaladas a partir de `D:/Documentos/Projetos_pessoais/Barber/.claude/skills`.

## Como usar

- Codex: leia `.agents/skills/<nome>/SKILL.md`.
- Claude: leia `.claude/skills/<nome>/SKILL.md`.
- Use as skills solicitadas explicitamente pelo usuário. Nas demais tarefas,
  escolha apenas as que forem pertinentes, conforme a descrição em `SKILL.md`.
- Leia integralmente as instruções da skill escolhida e suas referências
  obrigatórias antes de executar o trabalho.
- Resolva referências relativas a partir da pasta da própria skill.
- As instruções do usuário têm precedência. Observe também `AGENTS.md`.
- Ao atualizar uma skill local, mantenha as duas cópias sincronizadas.
- Este catálogo não exige carregar todas as skills em cada tarefa.
